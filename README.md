# OBJECTION! – The AI Card Duel

A Hearthstone-style courtroom card battler (Unity 6 WebGL). You're a rookie lawyer dueling three over-the-top AI lawyers. The big feature is **THE FORGE**: type any idea ("a pigeon that testifies against everyone") and Mistral designs a balanced, playable card on the spot, including its abilities, art and particle effect. The boss then trash-talks your new card live.

## Gameplay
- 1v1 duel. Credibility (HP) and Evidence (mana) go up by 1 each turn, up to 10.
- **Witnesses** (minions) and **Motions** (spells).
- Keywords: *Key Witness* (taunt), *Surprise Witness* (charge), *Lawyered Up* (shield), *Opening Statement* (battlecry), *Last Words* (deathrattle), *Each turn*.
- **THE FORGE:** you get one free use per duel, plus the *Legal Loophole* card. A Forge card is also offered as a reward after each win. Forged cards stay in your deck.
- Campaign: Maitre Bulldozer (aggro), then Mme Paperwork (control), then Lil' Verdict (chaos/steal). There's no game over: if you lose, just retry the duel.

## Architecture
- `Assets/Scripts/CardGame*.cs`: code-first Unity. Rendering is IMGUI on a 1280x720 virtual canvas, and particles/audio are procedural. The scene is generated by `Assets/Editor/BuildScript.cs`.
- `server/server.py`: Python stdlib server. It serves `webgl/` and proxies Mistral (`mistral-medium-latest`, JSON mode), so the key never reaches the browser.
  - `GET /api/content`: cards, decks, bosses (from `server/content.py`).
  - `POST /api/forge`: the LLM designs a card. The server validates it against a fixed effect vocabulary and **rebalances it with a points budget**.
  - `POST /api/taunt`: an in-character one-liner from the boss.
  - Every LLM call has an offline fallback, so the demo never freezes.
- Art is generated cartoon images in `Assets/Resources/Art`.

## Run
```bash
cp .env.example .env            # put your MISTRAL_API_KEY in .env (gitignored)
./build.sh                      # headless WebGL build into ./webgl (needs an activated Unity license)
python3 server/server.py        # http://localhost:8080
```
Unity 6000.0.84f1 with WebGL support is expected at `~/Unity/Hub/Editor/6000.0.84f1` (override with `UNITY=...`). To activate a license, sign in via Unity Hub (`unityhub --no-sandbox`).

The build is equivalent to running `Unity -batchmode -nographics -quit -projectPath . -buildTarget WebGL -executeMethod BuildScript.BuildWebGL` (gzip + decompression fallback).
